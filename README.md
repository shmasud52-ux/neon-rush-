# NEON RUSH — Cyber Highway Survival

A polished, mobile-first endless cyberpunk highway survival game.
Pure **HTML + CSS + Vanilla JS + Canvas**. No build system, no backend.

## 🚀 Run locally

1. Download / clone the folder.
2. Open `index.html` in any modern browser.
3. Play with **swipe / on-screen arrows / keyboard ← →**.

## 🌐 Host on GitHub Pages

1. Push the whole `neon-rush` folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Source: `Deploy from a branch` → `main` → `/ (root)`.
4. Open `https://<your-user>.github.io/<repo>/` on your phone.

All asset paths are **relative**, so it works inside a repo subpath.

## 🎮 Controls

| Action | Mobile | Desktop |
|---|---|---|
| Move left | Swipe left / ◀ button | ← / A |
| Move right | Swipe right / ▶ button | → / D |
| Pause | ⏸ button | Esc |

## 🧩 Adding your own art & sound

Just drop files into the matching folders — **no code changes needed**.
